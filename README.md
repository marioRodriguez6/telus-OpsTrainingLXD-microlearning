# TELUS Digital — De-escalating Frustrated Customers

A self-paced, browser-based microlearning prototype introducing active listening, empathy, and the Pause, Paraphrase, Probe (3 P's) framework.

## Course flow
1. Welcome and learning objectives
2. Understanding customer frustration
3. Active listening and empathy
4. Introduction to the 3 P's
5. Pause, Paraphrase, and Probe learning screens
6. Four customer-support scenarios with five decision checks and conditional feedback
7. Sample call transcript review: identify two dismissive statements, compare original and improved wording, and retry if needed
8. Key takeaways and completion

## Run locally
Open `index.html` in a modern web browser. The course is a static site and does not require a backend or build step.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, this README, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site and use the generated URL.
