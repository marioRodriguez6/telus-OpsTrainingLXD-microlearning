# TELUS Digital – De-escalating Frustrated Customers

A standalone, responsive 15-minute microlearning prototype built with HTML, CSS, and JavaScript.

## Course flow
1. Welcome
2. Learning objectives
3. Understanding customer frustration
4. Active listening and empathy
5. The 3 P's overview
6. Pause
7. Paraphrase
8. Probe
9. Four guided customer scenarios with dedicated positive/incorrect feedback screens and retry paths
10. Communication self-check
11. Key takeaways and completion

## Run locally
Open `index.html` in a modern browser. Keep the `assets` folder alongside it so the customer feedback portraits load.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `README.md`, and the `assets` folder to the repository root.
3. Open Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/(root)`, then Save.
5. Wait for GitHub Pages to provide the public URL.

This is a prototype, not an LMS-connected course. It does not transmit learner scores to an LMS.
